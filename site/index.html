The initial fixture replays snapshots generated by the Rust solver during the Pages build. Uploaded OBJ and self-contained GLB triangle meshes run live through the same cloth-lab Rust core compiled to WebAssembly. Mesh formats provide geometry only here: seams, patterns, measured fabric properties, skins, and animation are not inferred when the source does not provide supported simulation semantics.
